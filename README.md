# Портфолио — Эльвира Галиева

Одностраничный сайт-портфолио на чистом HTML / CSS / JS, без сборки.

## Структура

```
index.html   — разметка и тексты
style.css    — стили (CoFo Sans, серый #6B6B6B, скругления 10/16/20 px)
script.js    — настройки: ссылки, картинки, навыки + логика
images/      — сюда кладутся фотографии
fonts/       — сюда кладутся файлы шрифта CoFo Sans
```

## Как добавить картинки

Положи файл в `images/` с одним из этих имён (подойдёт `.jpg`, `.jpeg`, `.png` или `.webp`):

| Файл              | Где на сайте                              | Размер (минимум) |
|-------------------|-------------------------------------------|------------------|
| `hero`            | фото на первом экране (на весь экран)     | 1600×900          |
| `case-process`    | обложка «Процессы команды»                | 1100×930         |
| `case-sites`      | обложка «Сайты для застройщиков»          | 1100×930         |
| `case-ab`         | обложка «A/B-тесты и продукт»             | 1100×930         |
| `case-myolimp`    | обложка «MyOlimp: дизайн с нуля»          | 1100×930         |
| `logo-idalite`    | логотип Ида.Лайт в «Опыте работы»         | 180×180          |
| `logo-xploration` | логотип Xploration                        | 180×180          |
| `logo-myolimp`    | логотип MyOlimp                           | 180×180          |
| `logo-freelance`  | иконка «Фриланс»                          | 180×180          |

Пока файла нет, на его месте серый плейсхолдер. Обложки кейсов автоматически появляются и во всплывающем превью у навыков.

## Шрифт CoFo Sans

Положи в папку `fonts/` файлы шрифта с web-лицензией (формат `.woff` или `.woff2`, имена как в таблице; для `.woff2` поменяй расширение в начале `style.css`):

| Файл                     | Начертание   |
|--------------------------|--------------|
| `CoFoSans-Regular.woff`  | Regular 400  |
| `CoFoSans-Medium.woff`   | Medium 500   |
| `CoFoSans-Bold.woff`     | Bold 700     |

Пока файлов нет, сайт показывается запасным шрифтом Inter. Пробные (trial) версии шрифта не подходят: в них заменены буквы F и Ф. SemiBold 600 в наборе нет — там, где в шкале стоит 600 (H3, Label), браузер показывает Bold 700. Шрифт платный (Contrast Foundry): перед публикацией проверь, что лицензия разрешает использовать его на сайте (web-лицензия).

## Как поменять ссылки

Открой `script.js`, блок `LINKS` в самом начале, и замени `"#"` на свои адреса (CV, Telegram, почта, Behance, LinkedIn, кнопки «кейс →»).

## Как выложить на GitHub Pages

1. Создай новый репозиторий на github.com (например, `portfolio`).
2. Нажми **Add file → Upload files** и перетащи всё содержимое этой папки (вместе с папкой `images`).
3. **Commit changes**.
4. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<твой-логин>.github.io/portfolio/`.

Посмотреть локально: просто открой `index.html` в браузере.
